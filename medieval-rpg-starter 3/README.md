# Medieval Open-World RPG

Стартовый 3D-прототип средневековой RPG с открытым миром на **Three.js** с поддержкой `.glb`-ассетов.

## Что уже реализовано
- Процедурный ландшафт, лес и замок на холме.
- Управление от первого лица (`WASD`, `Shift` спринт, `Space` прыжок, мышь с Pointer Lock).
- Боевая система: удар мечом (`ЛКМ`), блок щитом (`ПКМ`), шкала выносливости.
- Переключение погоды и времени суток (`T`: ясный день, туманный рассвет, ночная буря).
- Встроенный загрузчик `GLTFLoader`: при добавлении `assets/models/weapons/longsword.glb` модель автоматически подменяет меч игрока.

## Структура папок под ассеты
```text
assets/
├── models/
│   ├── weapons/       # longsword.glb, axe.glb, shield.glb...
│   ├── armor/         # шлемы, кирасы, плащи (.glb)
│   ├── characters/    # рыцари и NPC (.glb)
│   └── environment/   # деревья, камни, скалы (.glb)
├── textures/          # PBR-карты (ambientCG, Poly Haven)
└── audio/             # звуки боя, погоды и музыка
```

## Быстрый запуск локально
```bash
npx serve .
```
Или включи **GitHub Pages** в настройках репозитория (`Settings → Pages → Branch: main`), чтобы запускать игру прямо по ссылке.
